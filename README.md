# Gametophyte growth rate data and R code

Gametophyte growth rate data and R code associated with the publication "Impacts of marine heatwave duration and intensity on microscopic life stages of giant kelp (Macrocystis pyrifera)," by Zulie A. Malone and Brooke L. Weigel.

In this paper, we studied the interactive effects of marine heatwave duration and intensity on the thermal tolerance of giant kelp (Macrocystis pyrifera) gametophytes. We examined the impact of benthic conditions on gametophyte thermal tolerance by culturing gametophytes on both benthic ceramic tiles and in petri dishes, so this dataset contains all of the data associated with each experiment:

The file "Tile_exp_gametophyte_code.R" contains the R code to analyze and graph the gametophyte growth rates from the marine heatwave experiments conducted with gametophytes cultured on benthic ceramic tiles. The data that corresponds to the code is contained in the file "Tile_exp_gametophyte_data.R"

The file "Petri_dish_exp_gametophyte_code.R" contains the R code to analyze and graph the gametophyte growth rates from the marine heatwave experiments conducted with gametophytes cultured in petri dishes. The data that corresponds to the code is contained in the file "Petri_dish_exp_gametophyte_data.R"
